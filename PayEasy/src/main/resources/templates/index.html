PayEasy

Offline UPI mesh-routed deferred settlement demo

Spring Boot 3.3 · Java 17 · H2 ▶ Live Simulation

PayEasy simulates how UPI payments can work when there is no internet. A sender encrypts a payment on their phone, the packet hops across nearby devices over a Bluetooth-style mesh, and when any device regains connectivity it uploads the packet to this backend for secure settlement.

1Encrypt payment with hybrid AES + RSA
2Gossip across virtual mesh phones
3Bridge node uploads when online
4Server decrypts & settles accounts

Core idea

Real-world mesh payments let strangers' phones forward encrypted packets without reading them. Only the server holding the RSA private key can decrypt and settle.

Security features

  • Hybrid encryption: AES-GCM payload + RSA-OAEP key wrap
  • SHA-256 PIN hashing before encryption
  • Per-payment nonce prevents duplicate ciphertext collisions
  • signedAt freshness check blocks replay attacks
  • Packet hash idempotency rejects duplicate uploads

Tech stack

  • Spring Boot Web + Data JPA + Thymeleaf
  • In-memory H2 database for demo accounts
  • Guava SHA-256 hashing utilities
  • ConcurrentHashMap mesh simulator
